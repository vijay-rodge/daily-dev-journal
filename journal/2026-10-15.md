# Daily CS Lesson: Understanding Python Decorators

**Topic:** Python (Advanced Functions)

### 1. What are Decorators?
In Python, a decorator is a design pattern that allows you to "wrap" another function to extend its behavior without permanently modifying the original function's source code. Think of it like a gift wrapper: the gift inside remains the same, but the wrapper changes how it is presented or handled.

### 2. Code Example: A Simple Timer
This decorator calculates how long a function takes to execute.

```python
import time

def timer_decorator(func):
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"Function '{func.__name__}' took {end_time - start_time:.4f} seconds.")
        return result
    return wrapper

@timer_decorator
def calculate_sum(n):
    return sum(range(n))

# Running the decorated function
print(f"Result: {calculate_sum(1000000)}")
```

### 3. How It Works
*   **The Wrapper:** The `timer_decorator` defines an inner function called `wrapper`. This function captures the logic we want to add (timing).
*   **`*args` and `**kwargs`:** These allow the wrapper to accept any number of positional and keyword arguments, ensuring the decorator works for any function regardless of its parameters.
*   **The `@` Symbol:** Placing `@timer_decorator` above `calculate_sum` is "syntactic sugar." It is equivalent to writing `calculate_sum = timer_decorator(calculate_sum)`.
*   **Execution:** When you call `calculate_sum(1000000)`, you are actually executing the `wrapper` function, which then calls the original `calculate_sum`.

### 4. Real-World Application
Decorators are heavily used in web frameworks like **Flask** and **Django**. For example, they are used to handle authentication:
```python
@login_required
def view_dashboard():
    # Only runs if the user is logged in
    return "Welcome to your dashboard!"
```
If the user isn't logged in, the decorator redirects them to the login page before the `view_dashboard` function is ever executed.

### 5. Practice Task
Create a decorator called `@log_call` that prints the message "Function is being called!" every time the function it wraps is executed. Apply it to a simple function that returns the square of a number, then call that function.

### 6. Key Takeaway
Decorators are a powerful way to implement "Cross-Cutting Concerns"—functionality that needs to be applied to many parts of an application (like logging, timing, access control, or caching) without duplicating code inside every function.
