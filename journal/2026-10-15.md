## Topic: Introduction to Python Decorators

### Beginner-Friendly Explanation
In Python, a **decorator** is a powerful design pattern that allows you to modify the behavior of a function without changing its actual code. Think of it like "wrapping" a gift: the gift inside (the function) stays the same, but the wrapping paper (the decorator) changes how it is presented or handled.

Technically, a decorator is a function that takes another function as an argument, adds some functionality, and returns a new function.

### Code Example: A Simple Timer
```python
import time

def timer_decorator(func):
    def wrapper():
        start_time = time.time()
        func()
        end_time = time.time()
        print(f"Function took {end_time - start_time:.4f} seconds to run.")
    return wrapper

@timer_decorator
def display_message():
    print("Processing task...")
    time.sleep(1) # Simulating a delay
    print("Task complete!")

# Running the decorated function
display_message()
```

### How the Code Works
1.  **The Wrapper:** Inside `timer_decorator`, we define a nested function called `wrapper`. This function performs the extra tasks (starting the timer, calling the original function, and ending the timer).
2.  **The `@` Symbol:** Placing `@timer_decorator` above `display_message` is syntactic sugar. It tells Python: "Pass `display_message` into `timer_decorator` and replace the original `display_message` with the result."
3.  **Execution:** When we call `display_message()`, we are actually calling the `wrapper` function, which handles the timing logic automatically.

### Real-World Application
Decorators are heavily used in web frameworks like **Flask** and **Django**. For example, they are used to define routes:
```python
@app.route('/home')
def home():
    return "Welcome to the homepage!"
```
Here, the `@app.route` decorator tells the web server that the function `home()` should be triggered whenever a user visits the `/home` URL. They are also widely used for logging, access control (authentication), and performance monitoring.

### Key Takeaway
Decorators allow you to follow the **DRY (Don't Repeat Yourself)** principle by extracting cross-cutting concerns—like timing, logging, or security—out of your main business logic and into reusable wrappers.
