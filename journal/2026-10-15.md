## Topic: Databases (Introduction to SQL Queries)

### Beginner-Friendly Explanation
A database is a structured way to store, retrieve, and manage data. Most databases use **SQL (Structured Query Language)** to communicate. Think of a database as an Excel spreadsheet on steroids; instead of manually clicking cells, you use SQL commands to ask the database for specific information.

The most common operation is the `SELECT` statement, which allows you to fetch data from a table. You can filter this data using a `WHERE` clause to find exactly what you need.

### Runnable Code Example (Python using `sqlite3`)
Python includes a built-in library called `sqlite3` that allows you to interact with a lightweight database file.

```python
import sqlite3

# 1. Connect to an in-memory database (temporary for this session)
connection = sqlite3.connect(':memory:')
cursor = connection.cursor()

# 2. Create a table
cursor.execute('CREATE TABLE Employees (name TEXT, department TEXT, salary INTEGER)')

# 3. Insert data
employees = [('Alice', 'Engineering', 90000), ('Bob', 'Sales', 60000), ('Charlie', 'Engineering', 85000)]
cursor.executemany('INSERT INTO Employees VALUES (?,?,?)', employees)

# 4. Query the database (Filter for Engineering department)
cursor.execute("SELECT name FROM Employees WHERE department = 'Engineering'")

# 5. Fetch and print results
results = cursor.fetchall()
print("Engineers found:", [row[0] for row in results])

connection.close()
```

### How the Code Works
1. **Connection:** We connect to a temporary database stored in RAM (`:memory:`).
2. **Setup:** We define a table named `Employees` with columns for name, department, and salary.
3. **Execution:** We use `cursor.execute` to run SQL commands. The `?` placeholders prevent SQL injection, a best practice for security.
4. **Filtering:** The command `SELECT name FROM Employees WHERE department = 'Engineering'` tells the database: "Give me the names, but only for people whose department matches 'Engineering'."
5. **Retrieval:** `fetchall()` gathers all rows that matched our criteria.

### Real-World Application
Every major website you use—Amazon, Instagram, or your bank's portal—uses SQL databases. When you search for a product on Amazon, the website sends a `SELECT` query to their database to find items matching your keywords. When you log in, the database checks your credentials against a `Users` table.

### Key Takeaway
SQL is a declarative language, meaning you describe *what* data you want rather than *how* the computer should find it; the database engine handles the complex work of retrieving that data efficiently.
