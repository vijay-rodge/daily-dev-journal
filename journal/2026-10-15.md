# Daily CS Lesson: Understanding Python Decorators

**Topic:** Python (Advanced Concepts)

### 1. What is a Decorator?
In Python, a decorator is a design pattern that allows you to "wrap" another function to extend its behavior without permanently modifying the original function's source code. Think of it like a gift wrapper: the gift (the function) is still the same, but the wrapper (the decorator) adds extra functionality, such as logging, access control, or timing, before or after the function runs.

### 2. Code Example
Here is a simple decorator that measures how long a function takes to execute:

```python
import time

def timer_decorator(func):
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"Function '{func.__name__}' took {end_time - start_time:.4f} seconds.")
        return result
    return wrapper

@timer_decorator
def calculate_squares(n):
    return [i**2 for i in range(n)]

# Execution
data = calculate_squares(1000000)
```

### 3. How the Code Works
1. **The Decorator (`timer_decorator`)**: It is a function that takes another function (`func`) as an argument.
2. **The Inner Function (`wrapper`)**: This function defines the new behavior (timing the start and end) and calls the original function using `*args` and `**kwargs` to accept any number of input arguments.
3. **The `@` Syntax**: The `@timer_decorator` syntax is "syntactic sugar." It is equivalent to writing `calculate_squares = timer_decorator(calculate_squares)`.
4. **Execution**: When `calculate_squares(1000000)` is called, it actually triggers the `wrapper` function, which handles the timing and then executes the math logic.

### 4. Real-World Application
Decorators are heavily used in web frameworks like **Flask** or **Django**. For example, they are used to handle authentication:
* `@login_required`: If a user tries to access a profile page, this decorator checks if they are logged in. If not, it redirects them to the login page before the profile function ever runs.

### 5. Practice Task

### 6. Key Takeaway
Decorators are a powerful way to implement **DRY (Don't Repeat Yourself)** principles by extracting common utility logic (like logging, timing, or authorization) out of your core business functions.
